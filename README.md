# Data Analytics - Proyectos y entregas

Repositorio de trabajos prácticos y proyectos desarrollados durante mi formación en Data Analytics.

## RetailPro

RetailPro es un proyecto progresivo de Data Analytics orientado al diseño, construcción y análisis de una base de datos relacional de ventas de productos tecnológicos.

A lo largo de los distintos módulos se trabajó sobre el mismo proyecto, incorporando progresivamente modelado de datos, consultas SQL, procesos ETL, Power BI, relaciones entre tablas, tabla calendario y medidas DAX.

## Herramientas utilizadas

- SQL Server
- SQL Server Management Studio (SSMS)
- Power BI
- Power Query
- DAX
- GitHub

## Estructura del repositorio

### RetailPro
Contiene los scripts SQL y la documentación desarrollada en las primeras etapas del proyecto.

### M6 - Pipeline ETL
Proceso ETL desarrollado en Power BI utilizando Power Query para la limpieza, transformación y preparación de los datos.

### M8 - Checkpoint 2 DAX
Modelo de datos en Power BI con relaciones activas, tabla calendario y medidas DAX para análisis temporal y comercial.

## Cómo ejecutar los scripts SQL

1. Abrir SQL Server Management Studio.
2. Conectarse a una instancia de SQL Server.
3. Abrir los archivos `.sql` ubicados en la carpeta `RetailPro`.
4. Ejecutar primero el script que crea la base de datos, las tablas y los registros necesarios.
5. Ejecutar posteriormente los scripts de consultas siguiendo el orden de los módulos.
6. Revisar los resultados obtenidos en SSMS.

Es importante ejecutar primero la estructura y carga de datos, ya que las consultas posteriores dependen de que las tablas y relaciones ya existan.

## Objetivo del proyecto

Aplicar un flujo de trabajo de Data Analytics que integra modelado relacional, SQL, limpieza y transformación de datos, modelado en Power BI y creación de medidas DAX para obtener información útil para la toma de decisiones.
