# Ventas Tech DB

Proyecto de práctica de Data Analytics orientado a la creación de una base de datos relacional en SQL Server.

La base contiene información de:

- categorías
- clientes
- productos
- ventas

El script incluye la creación de la base de datos, creación de tablas, claves primarias y foráneas, restricciones, carga de datos y consultas de validación.

## Cómo ejecutar el proyecto

1. Abrir SQL Server Management Studio.
2. Conectarse a una instancia de SQL Server.
3. Abrir el archivo `ventas_tech_db.sql`.
4. Ejecutar el script completo.
5. Verificar que se cree la base de datos `Ventas_Tech_DB`.
6. Revisar los resultados de las consultas `SELECT` incluidas al final del script.

## Motor utilizado

SQL Server.
